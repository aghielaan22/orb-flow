# 🔵 Orb Flow

> A physics-based touch-drawing mobile puzzle game.

---

## 📱 About the Project
**Orb Flow** is an intuitive, physics-driven mobile puzzle game designed for players of all ages. Players use touch-drawing mechanics to dynamically construct physical lines, guiding a falling energy orb safely through hazardous obstacles into a target portal. 

---

## 🛠️ Tech Stack & Tools
* **Game Engine:** Godot 4 (Mobile Renderer)[cite: 48, 64]
* **Language:** GDScript[cite: 48]
* **Ecosystem Services:** Huawei Mobile Services (HMS Core) - Game Service[cite: 78, 83]
* **Development Workflow:** AI-assisted game architecture and iteration loops[cite: 12, 31]

---

## 🎮 Core Features
* **Dynamic Line-Drawing Physics:** Real-time generation of physical collision segments (`StaticBody2D`) mapped to user touch inputs.
* **Minimalist UI/UX:** Clean portrait layout ($720\times1280$) optimized for mobile screens[cite: 70, 71].
* **HMS Integration:** Cloud-backed high score tracking and telemetry via Huawei Game Service[cite: 78, 83].
